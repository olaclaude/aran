# Fotos opcionales

La interfaz principal de la guía ya no utiliza una galería de fotos ni permite subir fotos.
Esta carpeta queda reservada para materiales visuales futuros del proyecto.

No es necesario añadir ninguna foto para que la web funcione correctamente. El flujo principal es:
- planning del día;
- Google Maps para los trayectos en coche;
- Wikiloc para los tracks;
- caché PWA para consultar la guía sin conexión.

Las fotos personales del viaje no se versionan en el repositorio.
