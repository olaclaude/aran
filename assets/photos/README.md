## Consejos

- Formato JPG; con 1600 px de ancho sobra para móvil y pantalla grande.
- Mientras falte alguna, la web muestra el marcador «Foto pendiente de incorporar al proyecto»
  y el hero degrada a su degradado verde: no hay que hacer nada más.
- Si queréis cambiar el pie de foto o el `alt`, se editan en `index.html` (bloque `.photos` de cada día).

> Estas fotos son materiales personales del viaje: **no se suben al repositorio público**.
> Este README documenta el hueco que dejan.
